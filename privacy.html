Какие данные используются

Сайт может использовать следующие данные:

  • email для регистрации, входа и восстановления доступа;
  • истории, которые пользователь создаёт на сайте;
  • лайки, лимиты генерации и технические статусы подписки;
  • технические данные браузера, необходимые для работы сайта;
  • данные localStorage и cookies, нужные для сессии, лайков, настроек и локального хранения истории.

Где хранятся данные

Для авторизованных пользователей данные аккаунта и пользовательские истории сохраняются в Supabase. Для пользователей без входа истории могут сохраняться только в localStorage браузера на текущем устройстве.

Для чего используются данные

Данные используются для входа в аккаунт, сохранения библиотеки, генерации историй и контроля лимитов.

Передача третьим лицам

Данные могут передаваться техническим сервисам, которые обеспечивают работу сайта: GitHub Pages, Vercel, Supabase и AI-провайдеру генерации. AI-провайдер получает только текст темы и параметров сказки, необходимых для генерации; не указывайте в них персональные данные ребёнка. Платёжные данные обрабатываются только выбранным платёжным сервисом при появлении доступной оплаты.
